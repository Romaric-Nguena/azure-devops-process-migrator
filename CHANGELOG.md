# Changelog

- Modernisation vers Node.js 20+ et TypeScript 7.0.
- Mise à jour vers `azure-devops-node-api` 16.
- Ajout d’un adaptateur de compatibilité avec le moteur de migration historique.
- Suppression des dépendances inutilisées et obsolètes du prototype navigateur.

- Correction des chemins de sortie pour Windows, Linux et macOS.
- Ajout de 13 tests automatisés hors connexion.
- Ajout d’une CI GitHub Actions sur Node.js 20, 22 et 24.
- Ajout de Dependabot pour npm et GitHub Actions.
